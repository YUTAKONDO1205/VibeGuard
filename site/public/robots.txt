# The site is six pages and five redirects. Only the six belong in an index.
#
# /go/* is disallowed rather than merely left out. Those paths count a click and
# then send the visitor to an extension store; a crawler that follows them
# inflates the count, and a redirect URL that reaches a search result lets a
# visitor land on a store without ever passing the install page, which is what
# the per-channel comparison is measured against. The Worker sends
# `X-Robots-Tag: noindex` on the same responses, because a rule here is a
# request and a header is an instruction on the response itself.

User-agent: *

Allow: /
Allow: /install
Allow: /rules
Allow: /research/compiler
Allow: /news
Allow: /privacy

Disallow: /go/

# There is no `Sitemap:` line, and its absence is deliberate.
#
# The directive takes an absolute URL, so it cannot be written until the site
# has a domain to be absolute about. Naming one before it is registered would
# ship a guess that crawlers follow. The sitemap itself is served at
# /sitemap.xml either way, and a crawler that reaches this file already knows
# the origin it fetched it from. Adding the line is one of the four edits listed
# in the deploy notes for the day a custom domain is attached.
