# smell-013-neg-two-routes

`MIN_GUARDED_ROUTES`. `requireLedgerRole` is mounted twice. Two is a pair of
routes that happen to share a guard; it is not yet a convention a third endpoint
can be accused of breaking, and telling this project that it departed from its
own practice would be telling it about a practice it does not have.
